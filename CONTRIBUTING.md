# Contributing

Use Node.js 24 and install the locked dependencies with `npm ci`. Run `npm run dev` for development. Before opening a pull request run `npm run typecheck`, `npm test` and `npm run package` (Python 3 required). Test the unpacked build in a separate Chrome or Brave profile.

Keep capture user-initiated, inference local and optional, and article text untrusted. For storage or model changes, include a regression test and describe compatibility with existing libraries and caches. State which checks used fixtures, an actual browser, or an installed model.

For issues include browser, extension version, OS and steps using public or synthetic material. Keep private reading data, answers, local paths, extension IDs and backups out of public reports.
