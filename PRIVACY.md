# PKI privacy policy

Personal Knowledge Intelligence runs in your Chrome or Brave profile. The developer operates no PKI server, account system, telemetry or advertising service. PKI does not sell information or transmit it to the developer.

**Capture and storage.** Clicking the toolbar grants temporary access to the active tab. Choosing Capture runs the bundled extractor on that page. PKI processes the page title, URL and readable text. Saving retains the plain-text article and its space assignments. Goals, notes, settings, cached analyses, recall drafts and assessment history are stored in extension-local browser storage. Drafts save as you type. PKI does not collect a browsing history. Opening an original article navigates your browser to that site under its own policies.

**Highlights and rediscovery.** Saving a selection retains the chosen text, nearby context, text position, color, note, space and parent article. Restoring highlights reads the active page on request and paints matching text ranges. Related-resource discovery processes current-page text only when requested. If a compatible local semantic index is available, the query goes to local Ollama. Disabling AI leaves keyword matching available.

**Local files and exports.** A PDF chosen in Library is parsed by a bundled worker. PKI retains the extracted text and page positions, using a local fingerprint of the file for duplicate detection. It does not upload or retain the original PDF. Markdown exports and backups can include private excerpts, annotations, notes and analyses. Treat downloaded files as private and remove them separately. Storage controls allow resource deletion, clearing derived caches, or resetting the extension after confirmation. Appearance is a local profile preference.

**Optional AI.** Enabling Ollama requests optional local host access. Explicit analysis sends the title, goal and selected text excerpts to the fixed loopback address on your computer. Checking an answer sends the question, expected answer, relevant passage and your written answer there. PKI requests local model execution. Downloading and configuring models is a separate action in Ollama. Saved reviews reopen without a network request. Notes and the article URL are excluded from analysis requests.

**Space questions, search and revision.** Asking a space question sends the question, up to two earlier questions from that space, and up to six article-title and excerpt pairs to the selected local model. Chat turns and source snapshots remain in the profile. Building the optional index sends saved passages to the local embedding model. Semantic searches send the search query to the same local service. Keyword fallback requires no embedding model. Local backups include chat and revision history. Derived vectors are excluded and can be cleared separately in Settings. Space chat history can be cleared in Spaces.

**Control and retention.** The profile retains the library and study records across restarts. The analysis cache retains up to 30 results. A backup is an unencrypted JSON file that can contain private reading and study material. Export and import are user actions. Keep exported files private and delete them separately when no longer needed. Removing the extension clears its local storage through the browser. Disable AI in Settings to keep using capture, organization and saved reviews locally.

For questions, use the repository contact channel and describe the issue without posting private articles, backups or learner answers. [Project repository](https://github.com/Afham08/personal-knowledge-intelligence)
